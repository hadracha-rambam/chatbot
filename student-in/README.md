# STUDENT iN

**כל מה שכדאי לדעת כסטודנט.ית ברמב״ם**

אפליקציית ווב בעברית (RTL), mobile-first, שמנגישה לסטודנטים המועסקים במשרת סטודנט
ברמב״ם את הזכויות והתנאים שלהם - בשפה פשוטה, בלי לחפש בתוך נהלים.

## הרצה

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # בנייה לפרודקשן
```

## מבנה

```
src/
  data/          ← כל התוכן. מקור אמת יחיד.
    types.ts       מודל הזכות (RightItem) ומטא-דאטה של מקורות
    rights.ts      כל הזכויות
    categories.ts  ששת עולמות התוכן
    faqs.ts        שאלות נפוצות
    quickActions.ts קיצורי דרך במסך הבית
    contacts.ts    מוקדי פנייה (ערכים ריקים עד שיתקבלו הפרטים)
    guide.ts       תהליך "מה רלוונטי אליי?"
  lib/search.ts  ← חיפוש עברי עם מילים נרדפות
  components/    ← רכיבים לשימוש חוזר
  pages/         ← מסכים
  styles/        ← tokens, base, components, pages
```

## עדכון תוכן

כל הזכויות יושבות ב-`src/data/rights.ts`. שינוי של אובייקט אחד מתעדכן אוטומטית
בכל המסכים: הבית, "הזכויות שלי", החיפוש, התהליך המונחה וכרטיס הזכות המלא.

לכל זכות יש מטא-דאטה של מקור:

| status | משמעות |
| --- | --- |
| `current_2026` | כלל רמב״ם 2026 - גובר על הנוהל הישן |
| `based_on_2022` | נוהל העסקת סטודנטים בשירות המדינה, 2022 |
| `needs_verification` | דורש אימות מול עדכוני 2026 |
| `rambam_specific` | תהליך פנימי ברמב״ם |

### כללי 2026 שגוברים על נוהל 2022

1. אין לעבור **120 שעות** בחודש קלנדרי.
2. ניתן לדווח ולקבל שכר עבור עד **8 שעות** עבודה ביום.
   אין חישוב או הצגה של שעות נוספות, ואין שימוש בכלל 8.5 השעות הישן.

## מה עדיין חסר

מקומות שבהם לא הוזן מידע ספציפי מסומנים במפורש בממשק
("פרטי התהליך ברמב״ם יעודכנו כאן", "יש לבדוק מול משאבי אנוש").
אין באפליקציה טלפונים, מיילים, שמות מערכות או סכומים שלא נמסרו.

## הערות טכניות

- React 18 + TypeScript + Vite + React Router + lucide-react.
- בלי backend, בלי DB, בלי התחברות, בלי קריאות API חיצוניות.
- התוכן מופרד לחלוטין מהתצוגה, כדי לאפשר חיבור עתידי ל-CMS או ל-Supabase
  בלי לשנות את הממשק.
